# Задание 6. CDN

В облачном CDN мы будем сохранять:
- статические файлы для сайта (JS, CSS и др.), они будут обновляться при релизах фронтэнда из CI/CD;
- кэшированные фотографии товаров в разных разрешениях:
  - бэкэнд интернет-магазина в своих ответах выдаёт ID фотографий фронтэнду;  
  - фронтэнд запрашивает ресайзы фотографий у CDN по заданному базовому URL;
  - облачный CDN проверяет наличие ресайзов в своём кэше, а если не находит у себя, то обращается на специальный эндпоинт нашего сервиса `media_management_service`.

За хранение статики у нас будет отвечать отдельный микросервис `media_management_service`. У него будут несколько эндпоинтов:
- добавление фотографии c загрузкой во внутренее `minio`-хранилище;
- удаление фотографии из внутреннего `minio`-хранилища
- отдача ресайза фотографии по заданному ID c заданным разрешением (с вызовом `imgproxy` под капотом).
